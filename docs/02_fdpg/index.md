# Übersicht

Das Forschungsdatenportal für Gesundheit (FDPG) ist per Web-Browser unter https://forschen-fuer-gesundheit.de/ erreichbar und gibt Auskunft über in der MII durchgeführte Forschungsprojekte. Es bietet Forschern die Möglichkeit Anfragen zur Machbarkeit für eine Forschungsfragestellung (Feasibility) abzusenden und direkt eine Antwort von den MII DIZ zu erhalten. Liefert die Anfrage ein für die Fragestellung ausreichendes Ergebnis, kann ein Datennutzungsantrag über das FDPG gestellt werden, mit dem Ziel Daten für eine Analyse zu erhalten oder eine verteilte Analyse an den MII Standorten zu initiieren.

In einem nur für die DIZ erreichbaren Bereich des FDPG, werden in einem Dashboard Daten zur Konnektivität und zum Umfang der für Forschungsfragestellungen zur Verfügung stehenden Daten zusammengefasst.

Es gibt die folgenden FDPG-Teilmodelle:

- FDPG [TM: 02.1 FDPG](detailed.md)
- Feasibility [TM: 02.2b FDPG ‐ Feasibility DSF](feasibility.md)
- KDS Report [TM: 02.4c FDPG ‐ KDS Report DSF](kds-report.md)
