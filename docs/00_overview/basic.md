# Vereinfachte Übersicht

Dieses Teilmodell beinhaltet eine grobe Struktur mit organisatorischen Bereichen (gestrichelte Rechtecke). Diese korrespondieren mit IT-Sicherheitsbereichen, welche die Anforderungen an die IT-Sicherheit in dem jeweiligen Bereich definieren. Den organisatorischen Einheiten sind jeweils Aufgaben (Rechtecke) zugeordnet.
